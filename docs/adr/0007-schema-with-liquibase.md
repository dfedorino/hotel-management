# ADR 0007. Схема БД в Liquibase, Hibernate только проверяет

## Контекст
При `ddl-auto=create-drop` схема «спрятана» в JPA-аннотациях, не версионируется и не видна проверяющему; часть ограничений (например, внешний ключ `bookings.user_id`) Hibernate не создавал.

## Решение
- Liquibase changelog в каждом сервисе (`src/main/resources/db/changelog`), YAML-changeset'ы с именованными ключами, ограничениями, индексами и комментариями к таблицам и колонкам.
- `spring.jpa.hibernate.ddl-auto: validate` — несоответствие сущностей схеме не даёт сервису стартовать.
- Индексы и уникальные ограничения описаны только в changelog (один источник правды).
- Демо-данные остаются в Java (`DemoDataInitializer`): даты считаются от текущего дня.

## Последствия
- Тест `DatabaseSchemaTest` в каждом сервисе проверяет порядок changeset'ов и наличие именованных ограничений и индексов.
- Новые изменения схемы — новым changeset'ом (пример: `003-bookings-slot-request-id`).
